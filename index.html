데이터 시트 · 출처와 가정, 실시간 연동 설계

지하철 토요일 시간표 (12~14시대, 이 프로토타입이 쓰는 원자료)

시간표에서 직접 확인한 것

  • 2호선 홍대입구 → 충정로: 같은 열차를 짝지으면 7~8분 (예: 13:12 → 13:19).
  • 5호선 충정로 → 광화문: 3~4분 (예: 13:27 → 13:30). 마천행과 하남검단산행이 번갈아 운행.
  • 3호선 경복궁 대화 방면: 6분 간격, 대화행과 구파발행 교대.

가정값 (실측 전, 관찰 세션에서 보정)

  • 출발지는 홍대입구역. 지하철은 승강장까지 걷는 시간 없이 1분 뒤 오는 열차부터 탈 수 있다고 봄. 273번 정류소까지는 역 출구에서 2분.
  • 충정로 2→5호선 환승 4분, 을지로3가 2→3호선 환승 4분.
  • 광화문역 승강장 → 광화문(정문) 10분, 경복궁역 승강장 → 광화문(정문) 8분, 광화문역 버스 정류소 → 정문 9분.
  • 2호선 충정로 → 을지로3가 5분, 3호선 을지로3가 → 경복궁 5분 (인접 역 시간표에서 추정).
  • 273번: 홍대입구역 정류소 출발, 평일 배차 7분을 토요일 8분으로 가정. 광화문역까지 22~28분 중 느린 쪽 28분으로 계획. 새벽 첫차 기준 운행시간은 약 18분.
  • 여유 시간 기본값은 설문 응답 중앙 구간의 상한(친구 5·수업 10·처음 가는 곳 15·면접·시험 30분).

실시간 연동 설계 (다음 단계)

  • 서울시 실시간 지하철 도착정보 API(realtimeStationArrival): 승차역의 다음 열차와 지연을 받아 엔진의 열차 시각에 더한다.
  • 서울시 버스도착정보 API(getArrInfoByRouteAll): 273번의 출발·도착 예정과 정체를 받아 버스 소요시간에 반영한다.
  • ODsay 대중교통 길찾기 API: 다른 출발지·목적지로 넓힐 때 경로 후보를 만든다. 지도 표시는 카카오 지도 JavaScript API로 바꾼다.
  • 세 API 모두 인증키가 필요하고 서울시 API는 HTTP로만 열려 있어 브라우저에서 바로 부를 수 없다. 키를 숨기고 HTTPS로 바꿔 주는 작은 중계 서버를 두고, 앱은 1분마다 값을 받아 지금처럼 다시 계산한다.
  • 막차(v0.4): 실시간 모드에서 서울시 응답의 막차 표시(지하철 lstcarAt, 버스 isLast1·2)가 오면 그 뒤로는 배차 추정 차를 이어 붙이지 않는다. 그래서 출발 마감이 자동으로 '막차 기준'이 되고 탑승권에 막차 안내가 뜬다. 시연 데이터(토 12~15시)에는 막차가 없다.
  • 이번 버전은 같은 계산을 시간표와 콘솔 주입값으로 돌린다. 연구 4(현장 다이어리)의 오즈의 마법사 방식과 같은 구조다.
